BookBazar - Book Marketplace Frontend

Created by: Lalit
Tech Stack: HTML, CSS, Vanilla JavaScript
Version: 1.0

---------------------------------------------------

Project Overview:

BookBazar is a fully responsive frontend college book marketplace system.
It includes interactive cart functionality, book filtering, search system,
login/signup demo, user dashboard, and modal-based UI system.

This project is designed for:
- College startups
- Student entrepreneurs
- Campus reselling platforms
- Developers building marketplace systems

---------------------------------------------------

Project Purpose:

BookBazar is a frontend college book marketplace designed to allow students to buy, sell, and exchange books within their campus community.

The goal of this project is to provide a simple, organized, and responsive platform where students can list their books for sale, browse available books, add items to cart, and manage marketplace activities through an interactive dashboard.

This project demonstrates how a real-world marketplace interface can function before integrating a backend or payment system.

Features:

- Responsive design (Mobile, Tablet, Desktop)
- Add to cart / Remove from cart
- Cart counter update
- Book search functionality
- Filter by categories
- Sell Book form
- Login / Signup demo modal
- User dashboard UI
- LocalStorage data persistence
- Smooth transitions and modern UI

---------------------------------------------------

How to Run:

1. Extract the ZIP file.
2. Open the project folder.
3. Double-click "index.html".
4. The website will run in your browser.

No installation required.

---------------------------------------------------

Customization Guide:

Change Logo:
- Replace file inside assets/logo/

Change Colors:
- Open css/style.css
- Edit root color variables at top

Change Book Data:
- Open js/script.js
- Edit book array object

---------------------------------------------------

Important Notes:

- This is a frontend-only demo.
- No backend or database included.
- Data is stored using browser localStorage.
